## Overview

This repository provides centralized configuration, community health templates, and the public organization profile for the entire Certsmith organization.

Under GitHub's organization health system, files located in this repository are automatically inherited as defaults across all current and future repositories under the `certsmith` organization unless overridden locally.

---

## Repository Structure

- `profile/README.md`: The public landing page for the organization rendered at [https://github.com/certsmith](https://github.com/certsmith).
- `.github/ISSUE_TEMPLATE/`: Standardized GitHub Issue Forms (`.yml`) for bug reporting, feature proposals, and security disclosures.
- `.github/ISSUE_TEMPLATE/config.yml`: Global issue configuration (disabling unstructured blank issues, directing questions to Discussions).
- `.github/DISCUSSION_TEMPLATE/`: Discussion form templates for architecture ideas, support questions, and announcements.
- `.github/PULL_REQUEST_TEMPLATE.md`: Standardized checklist and impact assessment for incoming contributions.
- [SECURITY.md](SECURITY.md): Coordinated vulnerability disclosure policy and supported version criteria.
- [CONTRIBUTING.md](CONTRIBUTING.md): Engineering standards, Conventional Commits formatting, and PR submission guidelines.
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md): Contributor Covenant v2.1 code of conduct.
- [SUPPORT.md](SUPPORT.md): Official support channels and self-service troubleshooting resources.
